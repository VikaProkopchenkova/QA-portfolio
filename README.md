Привет! Меня зовут Виктория. Я начинающий специалист по тестированию ПО.
В этом репозитории собраны практические работы, выполненные в рамках обучения тестированию ПО.

Проект: комплексное тестирование интернет-магазина
В рамках итогового проекта выполняла различные виды тестирования:
- Функциональное тестирование
- Приёмочное тестирование
- Регрессионное тестирование
- UI-тестирование
- API-тестирование
- Тестирование безопасности
- Тестирование аналитики

Практические навыки
- Составление тест-кейсов и чек-листов
- Разработка сценариев приёмочного и регрессионного тестирования
- Анализ требований и ожидаемых результатов
- Поиск, описание и документирование дефектов
- Проверка пользовательских интерфейсов
- Проверка API
- Работа с диаграммами состояний и переходов

Инструменты
- Postman
- Chrome DevTools
- Figma
- YouTrack
- Google Chrome
- Mozilla Firefox

Материалы портфолио
1. Итоговый проект
Описание заданий и выполненных работ по комплексному тестированию интернет-магазина.

2. Приёмочное тестирование
Набор тест-кейсов для проверки функциональности интернет-магазина.

Сценарии регрессионного тестирования с ожидаемыми результатами и учётом времени выполнения проверок.

4. Диаграмма состояний и переходов
Визуальное представление состояний и переходов тестируемой функциональности.
