Проект: комплексное тестирование интернет-магазина
В рамках итогового проекта выполнила:
1. Тестирование аналитики
- Проверка корректности работы аналитики.
- Поиск ошибок и несоответствий в передаче данных.
- Составление баг-репортов по обнаруженным дефектам.

2. Тестирование регистрации и авторизации
- Проверка формы регистрации и авторизации.
- Выявление ошибок валидации и работы пользовательских сценариев.
- Документирование дефектов.

3. Тестирование остатков товара и API
- Проверка функциональности отображения остатков товара на складе.
- Проверка хранения и передачи данных на бэкенде с использованием API.
- Составление баг-репортов по результатам проверок.

4. Тестирование безопасности
- Проверка безопасности приложения.
- Выявление потенциальных уязвимостей.
- Документирование обнаруженных проблем.

5. UI-тестирование
- Сравнение интерфейса с прототипом в Figma.
- Проверка отображения элементов в Google Chrome и Mozilla Firefox.
- Фиксация визуальных несоответствий.

6. Повторное тестирование (Retesting)
- Повторная проверка исправленных дефектов регистрации и авторизации.
- Повторная проверка функциональности остатков товара через API.
- Повторная проверка дефектов безопасности.


Практические навыки
