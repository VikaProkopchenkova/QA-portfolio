# QA Portfolio — Виктория Прокопченкова
Junior QA Engineer / ручное тестирование

Начинающий специалист по тестированию ПО. Прошла курс QA Engineer (Skillbox).
Здесь собраны учебные проекты: тест-кейсы, чек-листы, баг-репорты,
API-тестирование и итоговый проект — полный цикл тестирования интернет-магазина.

## Навыки и инструменты
- Ручное функциональное, регрессионное и приёмочное тестирование
- Составление тест-кейсов, чек-листов, баг-репортов
- API-тестирование: Postman
- Кроссбраузерное тестирование
- Сверка интерфейса с макетом: Figma
- Таск-трекер: YouTrack
- Анализ требований, диаграммы состояний и переходов
